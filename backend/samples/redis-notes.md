# Redis 中间件笔记

## 基本数据结构

String（缓存/计数器）、Hash（对象存储）、List（消息队列/时间线）、
Set（去重/交集并集）、ZSet（排行榜，score 排序）。
底层实现：跳表+哈希（ZSet）、压缩列表/快速列表（List）、整数集合（Set）。

## 持久化

- RDB：定时全量快照，恢复快，可能丢最后一次快照后的数据；
- AOF：追加写日志，默认 everysec，最多丢 1 秒数据，文件可重写压缩；
- 混合持久化（RDB+AOF）兼顾恢复速度与数据安全。

## 缓存三大问题

- 缓存穿透：查不存在的数据 → 缓存空值 + 布隆过滤器拦截；
- 缓存击穿：热点 key 过期瞬间并发打到 DB → 互斥锁重建 / 逻辑过期；
- 缓存雪崩：大量 key 同时过期 → 过期时间加随机抖动 + 多级缓存。
缓存与 DB 一致性：先更新 DB 再删缓存（延迟双删兜底），或订阅 binlog 异步删。

## 分布式锁

SET key value NX EX ttl 实现；防止误删用 value 存唯一标识（Lua 校验后删）；
主从切换可能丢锁 → RedLock（多节点过半加锁）或 etcd/zk 实现。
锁必须设置过期时间防死锁，业务时间超时需续期（看门狗）。

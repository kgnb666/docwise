# Python 编程基础

## 数据结构

- 列表 list：有序可变，append/pop 尾部操作 O(1)；
- 字典 dict：键值对，哈希表实现，查询平均 O(1)，Python 3.7+ 保序；
- 元组 tuple：不可变，可做字典键；
- 集合 set：去重与成员判断。

## 函数与装饰器

函数是一等公民：可作为参数传递、返回、存入容器。
装饰器本质是"接收函数返回函数"的语法糖，常用于日志、鉴权、缓存。
`@lru_cache` 就是标准库自带的一个装饰器，给纯函数加记忆化缓存。

## 异常处理

try/except/finally 捕获异常；raise 主动抛出。
原则：捕获具体异常类型而不是裸 except；把异常转成可读信息返回给调用方。

## 生成器与异步

生成器（yield）惰性求值，适合流式处理大文件。
async/await 用于 IO 密集任务（网络请求、数据库），配合 asyncio 单线程并发。

# 大模型与提示工程

## 上下文窗口与幻觉

大模型有上下文窗口限制（如 128K tokens），超出的部分看不到。
幻觉：模型"一本正经地编造"——因为它是概率生成，不是查数据库。
缓解：检索增强（RAG）提供事实依据、限制只依据资料回答、要求标注引用。

## 提示工程技巧

- 角色设定："你是一个严谨的助手"；
- 少样本示例：给 2-3 个输入输出对，比纯描述更稳；
- 思维链（Chain-of-Thought）：让模型先推理再给结论，复杂问题更准；
- 温度 temperature：低（0~0.3）稳定适合事实问答，高（0.7+）有创意适合写作。

## 微调与全参微调

提示工程解决不了时再考虑微调：用领域数据继续训练模型。
参数高效微调（LoRA）只训练少量低秩矩阵，省显存、效果好，是主流做法。

## Function Calling

给模型声明可用工具（名称、描述、参数 Schema），模型按需请求调用，
系统执行后把结果回填，模型再组织回答——这就是 Agent 的基础。

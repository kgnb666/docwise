# 数据库与 SQL

## 事务与 ACID

事务是一组要么全成功要么全回滚的操作。ACID：
原子性（Atomicity）、一致性（Consistency）、隔离性（Isolation）、持久性（Durability）。
隔离级别从低到高：读未提交、读已提交、可重复读、串行化；级别越高并发越低。

## 索引与 B+ 树

索引让查询不用全表扫描。主流数据库（MySQL InnoDB）用 B+ 树：
叶子节点存数据、内部节点只存键，扇出高、树矮，适合磁盘 IO。
覆盖索引（查询字段都在索引里）可以避免回表。

## 慢查询优化

- 用 EXPLAIN 看执行计划：type 是否为 index/range、是否走了索引；
- 避免 SELECT *、避免对索引列做函数运算（会失效）；
- 分页深翻页用"游标分页"（where id > last_id）而不是 offset 很大；
- 大表加缓存（Redis）抗热点读。

## 索引失效的常见场景

对索引列使用函数、隐式类型转换、前导通配符 LIKE '%xx'、联合索引不满足最左前缀。
